# Fortnite Tienda Story

Genera automáticamente imágenes verticales 1080x1920 con la tienda actual de Fortnite.

## Uso
- El workflow corre diariamente a las 00:00 UTC, equivalente a las 21:00 en Argentina (UTC-3).
- También puede ejecutarse manualmente desde GitHub Actions.
- Las imágenes aparecen en la carpeta `salida/`.

La fuente de datos es Fortnite-API.
